# Starbucks Beverage & Global Store Analytics | Power BI

## Project Overview

An interactive Power BI dashboard developed to analyze Starbucks beverage nutrition, caffeine levels, product categories, and global store distribution.

The project uses two datasets — `starbucks.csv` and `directory.csv` — to explore beverage characteristics, compare nutritional metrics, and understand Starbucks' global presence through interactive visualizations.

## Dashboard Preview

![Starbucks Power BI Dashboard](images/dashboard.png)

## Datasets

**1. Starbucks.csv**
- Beverage categories and beverage names
- Beverage preparation types
- Calories, sugar, protein, and caffeine
- Fat, carbohydrates, cholesterol, sodium, and vitamins

**2. Directory.csv**
- Store names and store numbers
- Ownership types
- City, country, and location details
- Geographic coordinates (latitude and longitude)

## Dashboard Highlights

### Key Performance Indicators (KPIs)
- Total Beverages: 33
- Average Sugar: 33.02 g
- Average Calories: 194.30 kcal
- Average Caffeine: 81 mg

### Interactive Filters
- Protein Range Filter – Explore beverages based on protein content.
- Beverage Preparation Filter – Filter beverages by preparation type.

### Visualizations
- Average Calories by Beverage Category – Compares calorie levels across beverage categories.
- Starbucks Global Presence – Visualizes store distribution across locations.
- Beverage Category Distribution – Shows the contribution of different beverage categories.
- Average Caffeine by Category – Compares caffeine levels across beverage categories.
- Top 5 Highest Caffeine Beverages – Highlights beverages with the highest caffeine content.

## Key Insights

- Coffee records the highest average caffeine level among the displayed categories (294 mg).
- Espresso Drinks rank next with 122 mg of caffeine.
- Frappuccino Blended and Frappuccino Light categories show relatively lower caffeine levels.
- Beverage categories differ considerably in their calorie and sugar content.
- The global store directory provides insights into Starbucks' international presence and store distribution.
